La solution informatique

Gérer des locations de salles avec une solution commune

Prixy répond à un besoin de gestion de locations de salles et de lieux événementiels. La réalisation associait une interface web et une partie applicative au sein d'un même projet mené collectivement.

Ce projet m'a demandé de comprendre une base de code partagée, d'intégrer mes modifications à celles des autres membres du groupe et de maintenir une version commune utilisable jusqu'aux phases de déploiement.

Collaboration & versionnement

Git utilisé dans les conditions d'un véritable projet d'équipe

Le dépôt GitLab était le point commun entre les membres du groupe. Il fallait récupérer, intégrer et publier les évolutions tout en conservant un historique cohérent du projet.

01 Récupérer

Synchroniser sa copie locale avec les modifications du groupe.

git pull
02 Enregistrer

Créer une étape claire dans l'historique avec un message précis.

git add → git commit
03 Résoudre

Traiter les conflits lorsque plusieurs modifications se rencontrent.

conflits Git
04 Partager

Envoyer ses commits vers le dépôt GitLab utilisé par le groupe.

git push
05 Déployer

Mettre à disposition une version exploitable de la solution.

mise en ligne
Un dépôt plus propre

Les fichiers générés par l'environnement de développement, notamment le dossier .idea, ont nécessité une gestion attentive pour ne pas perturber le dépôt partagé.

Un accès plus fiable

La configuration de GitLab a évolué d'une connexion HTTPS vers SSH afin de fiabiliser l'accès au dépôt distant.

Évolution du projet

S'adapter aux changements techniques

La solution a évolué pendant sa réalisation. Certains choix techniques ont changé et le groupe a dû poursuivre le développement avec les décisions finalement retenues, sans perdre la cohérence du travail déjà produit.

Version finale Technologies à confirmer

Cette partie sera complétée après récupération de la dernière version. Les anciennes technologies abandonnées ne seront pas présentées comme faisant partie du résultat final.
